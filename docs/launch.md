## One sentence

SkillVariants finds related Agent Skills and shows the exact instructions that changed, with paired sources you can inspect before adopting an adaptation.

## Short announcement draft

I am building SkillVariants for people who maintain SKILL.md files. It discovers related files on GitHub, collapses copies, and gives you a paired diff with line numbers, source hashes and explicit truncation.

You can also compare local files without credentials or a model service. The example explorer shows why a similar-looking instruction can add an approval checkpoint, preserve it, or reverse it.

There is an optional study workflow for your own coding agent. It is experimental: exact quotes do not prove an interpretation, and recurrence does not prove quality. The evaluation inputs, expected answers and separate predictions are published so others can challenge the method.

I would value a difficult source pair or a real maintenance decision where the output helped—or got in the way.

## Demonstration sequence

1. Show the approval reversal in the original example.
2. Run the local compare command from the README.
3. Switch between paired evidence, complete sources and unified diff.
4. Show a bounded GitHub shortlist with capture metadata when an authenticated live run is available.
5. End with a concrete request for false positives and maintainer feedback.
