# Web Acceptance — v0.2.0

Static explorer (`web/`), precomputed data only (`web/data/*.json`).
Verified against the release QA script (`scripts/release_qa.py`) and by
loading the pages from a local static server.

## Checks

| Check | Result |
|---|---|
| Home loads (hero, CTAs, three study cards) | PASS |
| Study page loads per family (source, variant/group/motif counts) | PASS |
| Motif detail opens (invariant, signature, counts, interpretation, tradeoff) | PASS |
| Representative links are exact SKILL.md blob URLs | PASS |
| Compare view renders precomputed similarity/diff/links | PASS |
| One unavailable source (deleted upstream ref) shows "source changed" instead of a broken compare | PASS (by design — documented behavior) |
| Suppressed motifs never appear as accepted | PASS |
| No backend, no auth, no secrets in bundle | PASS |
| Responsive layout (mobile-width CSS) and semantic HTML | PASS |

## Data integrity

Web counts and URLs are generated by `scripts/export_web_data.py` from the
runtime artifacts; `scripts/release_qa.py` asserts web counts equal artifact
counts and that no suppressed motif leaks into the accepted list.
